local function build(map, folder)
  for z, row in ipairs(map.tiles) do
    for x = 1, #row do
      local part = Instance.new("Part")
      part.Material = TILES[row:sub(x, x)].Material
      part.Position = origin + Vector3.new(x, 0, z) * map.scale
      part.Parent = folder
    end
  end
  ring.animate(30, function(t) return 1 - t end)
end

// faq

      
Questions, answered

    

    

      

        How do I get started?
        
Hit "Try the live API" — or grab a free key in the playground and POST to /v1/generate. No checkout, no GPU, no SDK install.

      

      

        Which engines are supported?
        
Roblox (Luau), Unity (C#), Godot (GDScript), and Unreal (C++), plus engine-agnostic levels as kodr-map-v1 JSON you can compile locally to any of the four.

      

      

        How much does it cost?
        
The free tier covers real projects. Larger plans scale with usage — and because the reference server is Apache-2.0, you can self-host with no per-seat fees.

      

      

        Can I self-host the API?
        
Yes. Everything the API runs on is open source — clone the repo, deploy the reference server, bring your own key. Same endpoints, same JSON.
