Roblox Studio

One server script builds the world and spawns combat waves the moment you press Play.

  1. Create a place from the Baseplate template.
  2. In ServerScriptService, add a new Script named NovaGame.
  3. Paste the bridge script below, press Play. The world builds itself in ~1s.
  4. Need a mesh instead? Generate with rex3d in the playground and drag the .glb into Studio.

FAQ

  

    
Do the models need internet?No. All three are offline-first. Nova-1 composes code from templates, rex3d builds meshes locally, Prism-1 paints in the browser. The server is pure Python.

    
How do I get an API key?Sign up on the site (or run the demo in server mode with python server.py). You get one key per model instantly, and can rotate them in the dashboard.

    
What is the difference between the playground and the API?Nothing under the hood. The playground calls the same three endpoints the API exposes, so anything you test here works identically in production.

    
Which Roblox version do the scripts target?The Luau bridge uses only core services — ServerScriptService, TweenService and Players — so it works on current Roblox Studio with no packages.

    
Is the generated code production-safe?Every output is a self-contained script or mesh. Nova-1’s Python games are runnable immediately; Roblox, Unity, Godot and Unreal outputs are drop-in scaffolds with wiring notes included.
